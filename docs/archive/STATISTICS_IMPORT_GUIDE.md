# 📊 統計數據匯入功能說明

## ✅ 功能說明

現在統計報表頁面支援匯入 CSV 統計數據，系統會根據統計數據自動重建簽到記錄。

## 📋 資料庫檢查

### 1. 確認資料庫表是否已建立

請在 Supabase Dashboard 的 SQL Editor 中執行以下查詢：

```sql
-- 檢查所有表是否存在
SELECT table_name
FROM information_schema.tables 
WHERE table_schema = 'public' 
  AND table_name LIKE 'estate_attendance_%'
ORDER BY table_name;
```

**應該看到 5 個表：**
- ✅ `estate_attendance_members` - 會員表
- ✅ `estate_attendance_meetings` - 會議表
- ✅ `estate_attendance_checkins` - 簽到記錄表
- ✅ `estate_attendance_prizes` - 獎品表
- ✅ `estate_attendance_lottery_winners` - 中獎記錄表

### 2. 如果表不存在，請執行建立腳本

執行檔案：`create_estate_attendance_tables.sql`

## 📥 CSV 匯入功能

### CSV 格式要求

標題行必須包含：
- `會員編號` 或 `編號`
- `姓名`
- `總會議數`
- `出席次數`
- `遲到次數`（可選）
- `代理出席`（可選）
- `缺席次數`（可選）
- `生命值`（可選）

### 匯入流程

1. **解析 CSV 檔案**
   - 自動從檔案名稱提取日期範圍（格式：`出席統計_YYYY-MM-DD_YYYY-MM-DD.csv`）
   - 如果無法提取，使用預設值：`2025-07-18` ~ `今天`

2. **創建會議記錄**
   - 自動在日期範圍內找到所有週四
   - 為每個週四創建會議記錄（如果不存在）

3. **重建簽到記錄**
   - 根據每個會員的「出席次數」
   - 按時間順序分配簽到日期
   - 只創建不存在的簽到記錄（不會覆蓋現有記錄）

### 使用步驟

1. 前往統計報表頁面：`http://localhost:3000/admin/attendance_management?tab=statistics`
2. 點擊「📤 匯入 CSV」按鈕
3. 選擇您的 CSV 檔案（例如：`出席統計_2025-07-18_2026-01-14 (1).csv`）
4. 系統會顯示預覽和確認對話框
5. 確認後開始匯入
6. 匯入完成後會顯示結果統計

### 注意事項

⚠️ **重要提示：**
- 匯入功能會根據統計數據**重建簽到記錄**
- 系統會**跳過已存在的簽到記錄**，不會覆蓋
- 簽到日期按**時間順序分配**（從最早的日期開始）
- 如果會員不存在，會跳過該筆數據並記錄錯誤

## 🔍 故障排除

### 問題：匯入不進去

**可能原因：**

1. **資料庫表未建立**
   - 解決：執行 `create_estate_attendance_tables.sql`

2. **會員不存在**
   - 解決：確保 CSV 中的會員編號在系統中存在
   - 可以先匯入會員資料

3. **日期範圍錯誤**
   - 解決：檢查 CSV 檔案名稱是否包含日期範圍
   - 格式：`出席統計_YYYY-MM-DD_YYYY-MM-DD.csv`

4. **CSV 格式不符**
   - 解決：確保標題行包含「會員編號」和「姓名」

### 檢查匯入結果

匯入完成後，可以：
1. 查看出席管理頁面，檢查簽到記錄是否已創建
2. 查看統計報表，確認數據是否正確
3. 查看瀏覽器控制台（F12），查看詳細的處理日誌
