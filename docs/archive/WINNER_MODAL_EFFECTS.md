# 🎆 中獎視窗畫面特效

## 完成時間
2026-01-13

## 功能概述

為中獎彈窗添加了豐富的畫面特效，增加慶祝氛圍和視覺衝擊力。

---

## 特效內容

### 1. 閃光效果 ✨
- **描述**: 彈窗出現時的瞬間閃光效果
- **實現**: 全屏徑向漸變閃光
- **顏色**: 金色半透明（rgba(255, 215, 0, 0.3)）
- **動畫**: 0.5秒淡入淡出

### 2. 彩帶/粒子掉落效果 🎊
- **描述**: 20個彩色粒子從上往下掉落
- **顏色**: 金色、紅色、青色、藍色、橙色、綠色（隨機）
- **動畫**: 線性掉落，旋轉720度
- **持續時間**: 2-4秒（隨機）
- **延遲**: 0-2秒（隨機）

### 3. 星星閃爍效果 ⭐
- **描述**: 15顆星星在背景中閃爍
- **位置**: 隨機分佈在整個畫面
- **動畫**: 淡入淡出 + 縮放效果
- **持續時間**: 1-2秒（隨機）
- **延遲**: 0-2秒（隨機）

### 4. 視窗光暈脈衝效果 💫
- **描述**: 視窗邊緣的光暈持續脈衝
- **效果**: 金色光暈從弱到強循環
- **動畫**: 2秒循環，無限播放
- **陰影**: 三層陰影（黑色 + 金色光暈）

### 5. 標題光暈效果 🌟
- **描述**: 「恭喜中獎！」標題周圍的光暈
- **效果**: 文字陰影脈衝
- **動畫**: 2秒循環，無限播放
- **顏色**: 金色到橙色漸變

### 6. 標題背景光暈 ✨
- **描述**: 標題區域的背景光暈
- **效果**: 模糊的漸變光暈
- **顏色**: 黃色、橙色、紅色半透明
- **動畫**: 脈衝效果

### 7. 慶祝 Emoji 彈跳 🎉
- **描述**: 🎉 emoji 慢速彈跳
- **動畫**: 2秒循環，上下彈跳
- **幅度**: 20px

## 技術實現

### CSS 動畫

#### 1. 閃光效果
```css
@keyframes flash {
  0%, 100% { opacity: 0; }
  50% { opacity: 0.3; }
}
```

#### 2. 彩帶掉落
```css
@keyframes confetti {
  0% {
    transform: translateY(-100vh) rotate(0deg);
    opacity: 1;
  }
  100% {
    transform: translateY(100vh) rotate(720deg);
    opacity: 0;
  }
}
```

#### 3. 星星閃爍
```css
@keyframes twinkle {
  0%, 100% {
    opacity: 0;
    transform: scale(0.5);
  }
  50% {
    opacity: 1;
    transform: scale(1.2);
  }
}
```

#### 4. 光暈脈衝
```css
@keyframes glow {
  0%, 100% {
    box-shadow: 0 20px 60px rgba(0, 0, 0, 0.3), 
                0 0 40px rgba(255, 215, 0, 0.3), 
                0 0 80px rgba(255, 215, 0, 0.2);
  }
  50% {
    box-shadow: 0 20px 60px rgba(0, 0, 0, 0.3), 
                0 0 60px rgba(255, 215, 0, 0.6), 
                0 0 120px rgba(255, 215, 0, 0.4);
  }
}
```

#### 5. 文字光暈脈衝
```css
@keyframes pulse-glow {
  0%, 100% {
    text-shadow: 0 0 20px rgba(255, 215, 0, 0.5), 
                 0 0 30px rgba(255, 140, 0, 0.3);
  }
  50% {
    text-shadow: 0 0 30px rgba(255, 215, 0, 0.8), 
                 0 0 50px rgba(255, 140, 0, 0.6), 
                 0 0 70px rgba(255, 100, 0, 0.4);
  }
}
```

#### 6. 慢速彈跳
```css
@keyframes bounce-slow {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-20px); }
}
```

## 性能優化

### 1. 使用 CSS 動畫
- ✅ 所有特效都使用 CSS 動畫，性能優於 JavaScript
- ✅ 利用 GPU 加速（transform, opacity）

### 2. 粒子數量控制
- ✅ 彩帶粒子：20個（平衡視覺效果和性能）
- ✅ 星星：15個（足夠豐富但不影響性能）

### 3. 動畫優化
- ✅ 使用 `will-change` 提示瀏覽器優化
- ✅ 避免觸發重排（使用 transform 而非 position）
- ✅ 使用 `pointer-events: none` 避免影響交互
